# CrowLink 2.01

표시 버전 2.01 · Windows/Store 2.0.1.0 · GitHub v2.0.1 · 2026-11-11

## 이번 버전의 변경

- 모바일–PC 채팅을 통합했습니다. 텍스트는 복사만 가능하며 TXT 자동 저장과 다운로드를 없앴습니다.
- 사진과 모든 첨부는 수락 전 원본을 전송하지 않습니다. “수락하면 다운로드 폴더에 저장됩니다”를 표시하고, 수락한 자료는 수신 완료 후 자동 저장합니다. PC는 설정의 수신 폴더 아래 MobileChat에 저장합니다. 휴대폰은 브라우저 다운로드를 자동 요청합니다. 브라우저 설정에 따라 저장 확인이 필요할 수 있습니다.
- 실패·취소·연결 종료의 미완성 파일은 정리합니다. 수락하여 저장이 끝난 파일과 송신 원본은 보존합니다. 텍스트와 대화 내용은 연결 종료 때 메모리에서 지웁니다.
- 사진 촬영·파일 선택 동안 최대 5분간 승인 세션을 유지·복구합니다. 일반 화면 이탈에는 기존 5초 종료 규칙이 적용됩니다. 중간에 끊긴 전송은 다시 보내야 합니다.
- 첨부 초안 삭제·비우기, 첫 입력 시 키보드 위 입력란 표시, 노란 화면 전환 버튼과 공통 연결 상태를 적용했습니다.
- Figma에서 제작한 선형 아이콘을 PC 메뉴·설정·도움말에 적용했습니다. 노란 부리 까마귀 앱 아이콘은 EXE와 Store에 동일하게 사용합니다.
- 앱 시작 시 일반 설치판은 GitHub, Store 설치판은 Microsoft Store에서 업데이트를 확인합니다.
- EXE 설치에서 바탕화면 바로가기 선택을 매번 표시합니다. Store는 OS 설치 UI를 변경할 수 없어 첫 실행 때 생성 여부를 묻습니다.

## 함께 사용할 수 있는 기존 기능

- Connect: 같은 로컬 네트워크의 PC 검색, 주소 연결, 연결 승인.
- Control: PC 사이 마우스·키보드 공유, 모니터 배치와 경계 전환, Ctrl+Alt+Esc 긴급 중지.
- Share: 여러 파일·폴더, 텍스트·이미지 클립보드 공유, 진행·취소와 수신 자료 확인.
- Quick: 양쪽에서 허용한 PC 연결에서 문서·미디어·ZIP 한 파일을 신속하게 복사. 자동 실행 없이 원본 보존.
- Mobile: 휴대폰 브라우저 QR 연결, 6자리 코드와 PC 승인, 터치패드·스크롤·키보드·펜·레이저·화이트보드 및 채팅·파일 교환.
- Black Crow / White & Light Pink 테마와 수신 폴더 설정.

## 설치 및 사용 범위

Windows 10 2004 이상 x64 공용 설치 파일에 .NET 런타임이 포함됩니다. Store 패키지는 별도 제공됩니다. 모바일은 웹브라우저로 접속합니다. 파일당 64MB, 채팅 이미지 12MB, 텍스트 100,000자, 연결당 합계 256MB입니다.

신뢰하는 동일 네트워크에서 사용하세요. 휴대폰 경로의 HTTP/WebSocket은 암호화되지 않습니다. 인터넷 포트를 공개하거나 공용 Wi-Fi에서 민감한 자료를 보내지 마세요. 실제 휴대폰의 다운로드 저장 결과는 브라우저 목록에서 확인해야 합니다.
