Connect와 PC 기능

같은 사설 네트워크에서 실행합니다. 검색되면 첫 장치가 표시되고, 마지막 연결 성공 장치가 검색되면 우선 표시합니다. 직접 선택한 장치는 유지합니다. Connect에서 승인된 PC를 연결하면 Control·Share·Quick을 사용할 수 있습니다. Mobile은 별도로 연결합니다.

Control은 연결 방향으로 마우스를 이동해 다른 PC에 입력을 전달합니다. Ctrl+Alt+Esc로 입력 공유를 종료할 수 있습니다. Share는 여러 파일과 클립보드를 전송합니다. Quick은 양쪽에서 신속 전송을 허용하고 Control을 연결한 경우 문서·미디어·ZIP 한 파일을 건별 승인 없이 복사합니다. 실행하지 않으며 원본을 삭제하지 않습니다. 탐색기에서 파일 하나를 선택해 연결 경계로 드래그하거나 Quick 영역에 놓으세요.

Mobile 연결

Mobile 메뉴에서 서버를 시작하고 QR 주소를 휴대폰 브라우저로 엽니다. 임시 코드 입력 후 PC에서 연결을 승인합니다. 연결이 종료되면 모바일 서버도 자동 중지합니다.

터치패드

한 손가락 이동·탭, 두 손가락 탭으로 오른쪽 클릭, 더블탭 후 드래그를 지원합니다. 두 손가락을 아래로 움직이면 세로 스크롤바가 아래로, 오른쪽으로 움직이면 가로 스크롤바가 오른쪽으로 이동합니다. 처음 선택된 축을 손가락을 뗄 때까지 유지해 대각선 흔들림을 줄입니다.

일반 포인터·레이저·형광펜·지시봉·검지 손가락을 선택할 수 있습니다. 레이저 궤적은 약 1.1초 동안 흐려지며 사라집니다. 방향 고정은 브라우저 지원에 따라 제한되며 미지원 브라우저는 휴대폰 자동 회전을 직접 끕니다.

펜과 화이트보드

펜은 기본 가로 화면이며 세로화면 옵션을 제공합니다. 대상 PC 모니터 비율에 맞춘 영역 안에 3×3 안내선과 중앙 표시가 있습니다. 휴대폰의 필기 궤적과 PC 필기를 함께 그리며 바깥 여백은 입력에서 제외합니다. PC 화면 미리보기는 전송하지 않습니다.

화이트보드는 대상 모니터를 흰색으로 덮습니다. 버튼을 다시 누르거나 PC의 Esc로 배경을 해제하며 필기는 유지합니다. 연결 종료 시 오버레이를 닫습니다. 지우기는 필기를 지우고, 화면 캡처는 PC 수신 폴더의 Captures에 저장합니다.

텍스트·클립보드

PC의 Mobile → 텍스트·클립보드 탭에서 글을 입력합니다. 실시간 키보드 연동을 켜면 해당 입력란의 글이 휴대폰 브라우저의 수신 화면에 반영됩니다. 휴대폰의 카카오톡 등 다른 앱에 직접 입력하는 기능은 포함하지 않습니다. 수신한 글을 복사해서 원하는 앱에 붙여넣으세요.

PC 클립보드 보내기는 텍스트 또는 PNG 이미지를 전달합니다. 휴대폰에서는 텍스트 보내기, 이미지 선택, 입력란에 이미지 붙여넣기를 사용할 수 있습니다. PC 수신함에서 받은 내용 복사를 누르면 PC 클립보드로 옮깁니다. 텍스트는 100,000자, 전송 PNG는 2MB 이하입니다. 휴대폰 이미지는 최대 변 1,600픽셀로 조정합니다. 이미지 복사를 지원하지 않는 브라우저는 저장 후 원하는 앱에 첨부하세요.
