# CrowLink 1.5.0

CrowLink 1.5 정식 버전입니다.

## 주요 변경 사항

- 휴대폰 브라우저를 무선 터치패드로 사용하는 Mobile Touchpad 추가
- QR 접속, 6자리 일회성 코드, PC의 매회 승인
- 인증번호 입력을 한 번의 탭으로 포커스하고 연결 후 인증창 자동 닫기
- 연결 중 모바일과 PC 상태등 점멸, 활성 상태에서 붉은 중지 버튼 표시
- 모바일 포인터 감도 0.5~5.0배와 선택형 속도 가속
- 터치패드 모드와 펜 모드 전환
- 펜 입력 영역을 선택한 PC 모니터와 화면 비율 유지 절대좌표로 매칭
- 연결 시 모바일 브라우저 전체화면 시도, 종료 시 원래 화면으로 복귀
- 휴대폰 연결 종료·네트워크 단절 시 PC 모바일 서버 자동 중지
- 한국어 사용 설명서와 표준 Windows 설치 마법사 추가
- Unicode 한국어 안내, 설치 폴더 선택, 시작 메뉴·바탕 화면 바로가기와 정상 제거 지원
- 도움말에서 GitHub 최신 릴리스 확인 및 설치 파일 다운로드 연결

## 배포 파일

- `CrowLink-1.5-Setup-win-x64.exe`: 권장 설치 파일, .NET 런타임과 한국어 설명서 포함
- `CrowLink-1.5-win-x64.zip`: 설치하지 않고 실행하는 휴대용 버전
- `SHA256SUMS.txt`: 배포 파일 무결성 확인값

## 확인 결과

- .NET 10 Release 빌드: 경고 0, 오류 0
- 자체 회귀 테스트: 25/25 통과
- 설치 EXE 실제 설치·바로가기 생성·Windows 제거 등록·제거 완료 검증
- 휴대용 ZIP의 `CrowLink.exe`가 게시 원본과 SHA-256 일치
- 실행 파일 버전: 1.5.0.0 / 제품 버전 1.5

## 주의 사항

- Windows x64 전용입니다.
- 설치 파일은 아직 코드 서명 인증서로 서명되지 않았습니다.
- Mobile Touchpad는 신뢰할 수 있는 같은 LAN/Wi-Fi에서만 사용하십시오.
- 펜 모드는 마우스 왼쪽 버튼 기반 드로잉이며 Windows Ink의 압력·기울기는 전달하지 않습니다.
- 공개 GitHub 저장소에서 누구나 업데이트와 설치 파일을 확인할 수 있습니다.
