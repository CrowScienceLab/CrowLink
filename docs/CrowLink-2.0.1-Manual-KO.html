CrowLink 2.01 사용 설명서

2026-11-11 · Crow ScienceLab · Windows/Store 버전 2.0.1.0

설치와 업데이트

Windows 10 2004 이상에서 x64 공용 EXE 설치 파일을 실행합니다. .NET 런타임이 포함됩니다. 바탕화면 바로가기 생성 여부는 설치 과정에서 선택합니다. Store판은 별도 배포하며 첫 실행 때 바로가기 생성 여부를 묻습니다. 일반판은 시작할 때 GitHub, Store판은 Store 업데이트를 확인합니다. 설정의 앱 업데이트에서도 확인할 수 있습니다.

PC 연결과 유용한 기능

  • Connect: 같은 로컬 네트워크의 PC를 검색하거나 주소를 입력하여 연결합니다. 상대 PC에서 연결을 승인합니다.
  • Control: 마우스와 키보드를 다른 PC로 넘깁니다. 모니터 배치를 설정하고 공유를 시작합니다. Ctrl+Alt+Esc로 즉시 중지할 수 있습니다. 관리자 창이나 Ctrl+Alt+Delete 제어는 지원하지 않습니다.
  • Share: 여러 파일·폴더를 초안에 추가하고 전송합니다. 잘못 고른 항목은 지울 수 있습니다. 기본적으로 상대가 수신을 승인하며 진행 확인과 취소를 지원합니다. PC 사이 텍스트·이미지 클립보드도 공유할 수 있습니다.
  • Quick: 양쪽 설정에서 허용하면 연결 경계 너머로 문서·미디어·ZIP 한 파일을 빠르게 복사합니다. 수신 파일을 자동 실행하거나 송신 원본을 삭제하지 않습니다.
  • Mobile: 휴대폰 브라우저를 터치패드·키보드·펜·레이저·화이트보드로 사용하고, 채팅에서 글과 파일을 주고받습니다.

Black Crow와 White & Light Pink 테마, 수신 폴더와 입력 감도를 설정할 수 있습니다.

휴대폰 연결

  1. PC Mobile 메뉴에서 서버를 시작합니다.
  2. 휴대폰을 같은 네트워크에 연결하고 QR 또는 표시된 주소를 웹브라우저로 엽니다.
  3. 6자리 코드를 입력한 뒤 PC에서 연결을 승인합니다.
  4. 상단의 노란 채팅·파일 / 터치패드 버튼으로 전환합니다. 연결 상태는 양쪽 화면에서 함께 표시됩니다.

텍스트는 복사만

글을 입력하거나 클립보드에서 붙여넣은 뒤 전송을 누릅니다. 완료 항목의 우측에는 완료 - 복사만 표시됩니다. TXT 파일을 자동 저장하거나 다운로드하지 않습니다. 대화는 현재 연결 동안 메모리에만 유지되며 종료하면 지워집니다.

사진·PDF·HWP·ZIP 등 첨부

파일 첨부에서 카메라·갤러리·파일을 선택합니다. 초안에서 각 항목을 삭제하거나 전체를 비운 뒤 전송할 수 있습니다. 붙여넣은 사진도 전송 전에는 초안입니다.

사진을 포함한 모든 첨부는 상대가 수락하기 전까지 원본을 보내지 않습니다. “수락하면 다운로드 폴더에 저장됩니다” 안내를 확인한 뒤 수락합니다. 수락하면 전송을 시작하고 완료 즉시 자동 저장합니다. 별도로 다운로드를 누를 필요가 없습니다. 이미지 미리보기 해석에 실패해도 원본 파일 전송은 가능합니다.

PC는 설정의 수신 폴더 아래 MobileChat에 저장합니다. 기본값은 사용자 다운로드 폴더의 CrowLink/MobileChat입니다. 상단 다운로드 폴더 열기로 바로 확인합니다. 이름이 겹치면 새 이름으로 보존합니다. 완료된 자료의 다운로드 링크는 다른 위치에 다시 보관할 때 사용할 수 있습니다.

휴대폰은 수신 완료 시 브라우저 다운로드를 자동 요청합니다. 브라우저 설정에 따라 저장 확인이나 여러 다운로드 허용이 필요할 수 있습니다. 실제 저장 결과와 위치는 브라우저 다운로드 목록 또는 파일 앱에서 확인하세요. 웹페이지는 OS의 저장 완료나 다운로드 취소 결과를 읽을 수 없습니다. 휴대폰 상단의 지원되지 않는 폴더 열기 버튼은 표시하지 않습니다.

실패·취소와 정리

전송 실패·취소·연결 종료 시 미완성 파일과 전송 버퍼를 정리합니다. PC 임시 수신 파일은 삭제 전용 핸들로 관리하여 프로세스가 종료되어도 OS가 삭제합니다. 저장 마무리 중 비정상 종료로 남은 앱 전용 staging 파일은 다음 연결 때 정리합니다. 휴대폰은 연결 종료 시 메시지·초안·임시 Blob과 URL 참조를 해제하며 브라우저 내부 저장 공간은 브라우저가 관리합니다.

수락하여 저장 완료된 파일은 사용자가 받은 자료이므로 대화가 끝나도 보존합니다. 송신 원본과 사용자가 다운로드한 자료를 임의로 삭제하지 않습니다. 이전 버전의 저장 파일도 사용자 자료와 구분할 수 없어 일괄 삭제하지 않습니다.

사진 촬영·파일 선택 중 연결

PC가 첨부 선택 대기를 확인한 뒤 선택 화면을 엽니다. 선택 중 입력 제어를 멈추고 최대 5분 동안 같은 승인 세션으로 돌아올 수 있습니다. 복귀 확인 후 전송하세요. 일반적인 화면 이탈에는 5초 후 종료가 적용됩니다. PC에서 종료하면 즉시 권한을 해제합니다. OS가 브라우저 페이지를 폐기하거나 시간이 지나면 다시 연결·승인해야 합니다. 중간에 끊긴 파일은 다시 첨부합니다.

용량과 연결 조건

파일당 64MB, 채팅 이미지 12MB, 텍스트 100,000자, 연결당 합계 256MB·메시지 200개·진행 중 16개, 초안 첨부 8개까지입니다. PC TCP 45100, 검색 UDP 45101, Mobile TCP 45102를 사용합니다. 같은 SSID여도 학교·게스트 Wi-Fi의 단말 격리가 있으면 연결이 막힐 수 있습니다.

신뢰하는 동일 네트워크에서 사용하세요. Mobile HTTP/WebSocket은 암호화되지 않습니다. 연결 코드와 PC 승인은 암호화를 대신하지 않습니다. 인터넷 포트를 공개하거나 공용 네트워크에서 민감한 자료를 보내지 마세요. 실제 휴대폰 기종·브라우저의 저장과 화면 전환 동작은 사용 환경에서 확인해야 합니다.
