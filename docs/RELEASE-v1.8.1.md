# CrowLink 1.8.1 — 변경 및 검증 기록

## 사용자 요청 반영

- 제목·설정·도움말·모바일 버전 표기를 어셈블리 버전 1.8.1로 통합.
- 사용자 화면의 Explorer 명칭을 Quick으로 정리. 기존 통신 규약과 설정 호환용 내부 식별자는 유지.
- 창 제어 아이콘 14→12 DIP, 버튼 36→34 DIP. 기본 창 높이 740→640 DIP.
- Black Crow 기본 테마 유지, White & Light Pink를 더 밝고 옅은 색으로 변경.
- 업데이트 확인을 도움말에서 설정으로 이동하고 OS의 x64/ARM64에 맞는 설치 파일 선택.
- 모바일 지우기·화면 캡처·화이트보드를 아이콘 3열과 작은 이름으로 구성. 터치패드도 같은 도구 행 사용(화이트보드는 펜 모드에서 활성화).
- PC 화면의 주기적 미리보기와 관련 안내 제거. 로컬 필기 궤적, 모니터 비율의 3×3 가이드 유지.
- 두 손가락 스크롤의 상하·좌우 방향 및 축 잠금 수정.
- 검색 장치 자동 선택, 이전 연결 성공 장치 우선, 직접 선택 유지.
- Mobile의 브라우저 범위 실시간 텍스트 연동 및 텍스트·PNG 양방향 교환.
- 레이저 잔상, 지시봉·검지 포인터, 네이티브 펜 오버레이 및 화이트보드.
- PC 이름 갱신, 어댑터별 검색, Control 세션·비상 키 충돌, 모니터 배치 공유 및 클립보드 수신 상태 처리 개선.
- Share 완료 알림과 수신 파일 드래그 복사. 허용된 연결에서 지원 파일 1개 Quick 전송.

## 검증 결과

- Release .NET 회귀 테스트 29개 통과.
- Node 모바일 테스트: 가로/세로의 4방향 스크롤, 축 잠금, 느린 이동, 손가락 해제, 로컬 필기, 화이트보드, 미리보기 제거, 텍스트 순서 통과.
- 루프백 TCP/WebSocket 검증은 실제 물리 입력 및 다른 휴대폰 앱 제어를 검증한 것이 아닙니다.
- x64·ARM64 독립 실행 설치 패키지 대상. ARM 기기에서 설치·실행한 결과는 아직 없습니다.
- 실제 두 PC의 경계 왕복, Quick 드래그, 혼합 DPI/다중 모니터, 학교 무선망, 휴대폰별 IME·이미지 복사는 추가 현장 확인이 필요합니다.

## 사용 범위

휴대폰 전체 OS/카카오톡 직접 제어, 주기적 PC 화면 미리보기, Wi-Fi Direct/Bluetooth 전송은 포함하지 않습니다. Mobile은 신뢰하는 사설망에서 사용하세요. Quick은 파일을 자동 실행하지 않으며 ZIP 내부의 안전성까지 보장하지 않습니다.
