설치PC 연결파일 공유입력 공유ExplorerMobile업데이트문제 해결

1. 설치와 첫 실행

  1. CrowLink-1.5-Setup-win-x64.exe를 실행하고 Windows 관리자 승인창을 확인합니다.
  2. 설치 마법사에서 설치 폴더를 확인하거나 변경합니다. 기본 위치는 C:\Program Files\CrowScienceLab\CrowLink입니다.
  3. 시작 메뉴 바로가기는 항상 생성되고, 바탕 화면 바로가기는 설치 옵션에서 선택할 수 있습니다.
  4. Windows 방화벽 알림이 나오면 신뢰하는 개인 네트워크에서만 액세스를 허용합니다.
  5. 통신할 모든 Windows PC에 CrowLink를 설치하고 같은 LAN 또는 Wi-Fi에 연결합니다.

CrowLink 설치 파일에는 .NET 10 실행 환경이 포함되어 별도의 SDK 설치가 필요하지 않습니다. 설치 파일은 아직 코드 서명 인증서로 서명되지 않았으므로 Windows가 게시자 확인 경고를 표시할 수 있습니다.

2. PC CONNECT

  1. 두 PC에서 CrowLink를 실행합니다.
  2. CONNECT 화면의 장치 목록에서 상대 PC를 선택하고 연결 요청을 누릅니다.
  3. 상대 PC가 장치 이름을 확인하고 허용하면 상단 상태가 연결됨으로 바뀝니다.
  4. 작업을 끝낼 때 연결 끊기를 누릅니다.

여러 PC가 같은 네트워크에서 실행되면 발견된 장치가 선택 목록에 표시됩니다. 기본값은 매 연결마다 상대방 승인이 필요합니다.

3. FILE SHARE와 클립보드

  1. 연결된 PC를 선택합니다.
  2. 파일 또는 폴더를 전송 영역에 놓아 보낼 목록을 만듭니다.
  3. 잘못 넣은 항목은 ×로 제거하고 전송 시작을 누릅니다.
  4. 진행 중인 항목은 취소할 수 있습니다.

텍스트와 PNG 이미지 클립보드도 전송할 수 있으며 송수신 내역은 Activity에 기록됩니다. 기본 수신 위치는 다운로드\CrowLink입니다.

4. MOUSE KEYBOARD CONTROL

Monitor topology에 두 PC의 실제 모니터가 사각형으로 표시됩니다. PC 묶음을 드래그해 실제 책상 배치처럼 맞춘 뒤 입력 공유를 시작하십시오. 지정한 경계로 커서를 밀면 상대 PC로 넘어가며 키보드, 한/영 전환, 일반 단축키가 함께 전달됩니다.

Ctrl+Alt+Esc는 원격 입력과 Mobile 입력을 즉시 중지하는 비상 단축키입니다. Ctrl+Alt+Delete는 Windows 보안 정책상 전달되지 않습니다.

5. EXPLORER

송신 PC의 Explorer 파일을 CrowLink OLE Lab으로 드래그하면 상대 PC의 안전한 임시 위치까지 전송됩니다. 수신 PC에 나타난 준비 완료 카드를 원하는 Explorer 폴더로 끌어 놓으십시오. 복사가 성공하면 CrowLink의 임시 원본은 자동 삭제됩니다.

SHARE는 지정된 수신 폴더로 바로 보내는 빠른 전송이고, EXPLORER는 수신 PC 사용자가 마지막 저장 폴더를 드래그로 선택하는 흐름입니다.

6. MOBILE TOUCHPAD

  1. PC와 휴대폰을 같은 Wi-Fi에 연결하고 PC의 MOBILE 화면에서 서버를 시작합니다.
  2. QR을 스캔하거나 주소를 열고 6자리 코드를 입력합니다.
  3. PC 승인창에서 휴대폰 이름과 주소를 확인해 허용합니다.
  4. 연결되면 인증창이 닫히고 모바일 상태등과 PC 상태등이 점멸합니다.

터치패드 모드

한 손가락 이동·탭, 두 손가락 탭·스크롤, 더블탭 후 이동 드래그를 지원합니다. 모바일 화면에서 감도 0.5–5.0배와 속도 가속 사용 여부를 조절할 수 있습니다. 세로와 가로 방향을 모두 사용할 수 있습니다.

펜 모드

대상 PC 모니터를 선택하면 휴대폰의 밝은 입력 사각형과 PC 화면을 비율을 유지한 절대좌표로 매칭합니다. 정확도를 위해 가로 방향을 권장합니다. 1.5의 펜 모드는 마우스 왼쪽 드로잉 방식이며 압력·기울기를 전달하는 Windows Ink 펜은 아닙니다.

종료

휴대폰의 붉은 중지 버튼, PC의 중지 버튼 또는 Ctrl+Alt+Esc를 사용합니다. 모바일 연결이 끊어져도 PC 서버가 자동으로 중지되고 꺼진 상태를 유지합니다.

7. 보안과 승인

  • Mobile은 사설 로컬 네트워크 접속, 6자리 임시 코드, PC의 매회 승인을 모두 사용합니다.
  • 기본 포트는 PC TCP 45100, 검색 UDP 45101, Mobile TCP 45102입니다.
  • 설정의 자동 승인은 신뢰할 수 있는 사내망·가정망에서만 사용하십시오.
  • 인터넷에 포트를 직접 개방하거나 공유기 포트 포워딩을 설정하지 마십시오.

8. 업데이트 확인과 다운로드

CrowLink 상단의 도움말을 열고 업데이트 확인 · 다운로드를 누릅니다. 공개 GitHub 릴리스의 버전을 확인하고 새 버전이 있으면 설치 파일 다운로드로 연결됩니다. 앱은 GitHub 비밀번호나 토큰을 저장하지 않습니다.

9. 문제 해결

  • PC가 검색되지 않음: 두 PC가 같은 서브넷인지, Windows 네트워크 프로필이 개인인지, UDP 45101이 차단되지 않았는지 확인합니다.
  • QR 주소가 열리지 않음: 휴대폰이 같은 Wi-Fi인지 확인하고 PC 방화벽에서 TCP 45102를 허용합니다.
  • 회사 네트워크: 클라이언트 격리, VLAN, 게스트 Wi-Fi 정책이 장치 간 통신을 차단할 수 있으므로 관리자에게 문의합니다.
  • 커서가 느림: 모바일 감도를 높이고 가속을 켭니다.
  • 펜 좌표가 어긋남: 올바른 대상 모니터를 선택하고 휴대폰을 가로로 둡니다.

10. 제거

Windows 설정 → 앱 → 설치된 앱 → CrowLink 1.5 → 제거를 사용하거나 시작 메뉴의 CrowLink 제거를 실행합니다. 사용자 설정과 로그는 %LOCALAPPDATA%\CrowLink에 남을 수 있으며, 필요하면 앱 종료 후 직접 삭제할 수 있습니다.
