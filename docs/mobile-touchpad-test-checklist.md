# CrowLink 1.5 Mobile Touchpad 실기기 확인표

PC와 휴대폰을 같은 Wi-Fi에 연결하고 `CrowLink-1.5-win-x64.zip`을 압축 해제한 뒤 `CrowLink.exe`를 실행합니다.

## A. 서버와 QR

- [ ] MOBILE 메뉴에서 `서버 시작`을 누르면 QR과 `http://사설IP:45102/mobile` 주소가 표시된다.
- [ ] 휴대폰 카메라로 QR을 스캔하면 CrowLink Mobile 페이지가 열린다.
- [ ] 화면을 세로·가로로 돌려도 Touch Area와 LEFT/RIGHT 버튼을 사용할 수 있다.
- [ ] 잘못된 6자리 코드는 거부된다.
- [ ] 올바른 코드 입력 후 PC에서 거부하면 휴대폰이 연결되지 않는다.
- [ ] 다시 요청하고 PC에서 허용하면 양쪽에 연결 상태가 표시된다.

## B. 제스처

- [ ] 한 손가락을 천천히 움직이면 정밀하게 커서가 이동한다.
- [ ] 빠르게 swipe하면 감도와 가속이 적용되고 끊김이 심하지 않다.
- [ ] 한 손가락 짧은 탭이 왼쪽 클릭으로 동작한다.
- [ ] 두 손가락 짧은 탭과 한 손가락 길게 누르기가 오른쪽 클릭으로 동작한다.
- [ ] 두 손가락 상하 이동이 수직 스크롤로 동작한다.
- [ ] 두 손가락 좌우 이동이 수평 스크롤을 지원하는 앱에서 동작한다.
- [ ] 더블탭한 두 번째 손가락을 떼지 않고 이동하면 드래그되고, 손을 떼면 버튼이 해제된다.
- [ ] 하단 LEFT/RIGHT 버튼을 누르고 떼는 동작이 정상이다.

## C. 안전 종료

- [ ] 드래그 중 Wi-Fi를 끄거나 브라우저를 닫아도 PC 마우스 버튼이 눌린 채 남지 않는다.
- [ ] PC의 `휴대폰 연결 종료`가 즉시 입력을 차단한다.
- [ ] `Ctrl+Alt+Esc`가 활성 모바일 세션을 즉시 끊는다.
- [ ] 다른 휴대폰이 같은 시간에 연결할 수 없다.
- [ ] Mobile 연결 종료 후 기존 PC 검색·파일 전송·키보드/마우스 공유가 정상이다.
